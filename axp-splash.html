axp

Optimize a CLI or MCP server for AI agents.

install

curl -fsSL https://decbench.ai/install.sh | sh

quickstart

axp run ./your-cli --task "your task here" --n 10

$ axp run ./moose --task ./tasks.yaml --n 10

how it works

  1. Test. axp runs your CLI through a task with a real AI agent. It records turns, tool-call errors, retries, latency, tokens, and exit status.
  2. Hypothesize. axp surfaces the trace so you can see where the agent stalled, retried, or wandered. You list the candidates to test in axp.toml: command shape, flag layout, help text, error messages, retry policy. Candidates can be CLI variants, MCP server variants, or a CLI vs MCP head-to-head.
  3. Prototype. axp generates each hypothesis as a working CLI variant in an isolated workspace.
  4. Re-test. Every variant runs against the same task set. axp prints the winner and writes a patch.
