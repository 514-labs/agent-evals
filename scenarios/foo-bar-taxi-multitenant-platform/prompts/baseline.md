Build a multi-tenant analytics platform for NYC taxi data. Fetch data from the TLC website, design the ClickHouse schema, create a semantic metrics layer with key business metrics, build API endpoints for trips, metrics, and summaries, add JWT-based tenant isolation so yellow and green cab tenants only see their own data, and instrument everything with Langfuse tracing. Auth materials are in /data/auth/ (JWT secret and pre-generated tenant tokens). Langfuse keys are available in your environment variables. Fill in /workspace/assertions.json when done.
